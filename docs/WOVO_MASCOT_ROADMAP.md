# Branded mascot / character roadmap

Status: post-launch only; not available or advertised as live.

A future client-created recurring mascot must be tenant-scoped and use only permissioned reference assets. The client must name the character, define approved personality/boundaries, confirm rights to every supplied brand element, and record likeness/voice consent for any real person represented.

Every generated episode remains a draft until the client approves the exact asset and caption. No identity impersonation, public-figure imitation, unapproved voice cloning, unsafe reference reuse, or automatic publication is permitted. Deletion/revocation must prevent future generation from revoked references while retaining the minimum audit evidence required to explain prior authorized use.
